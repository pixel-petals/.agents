# COC (Convention > Configuration)

Aims to reduce the number of decisions a developer must make by providing sensible defaults.

- **Sensible Defaults.** Makes intelligent assumptions about common setups.
- **Naming Conventions.** Specific naming patterns help the system understand your intent.
- **Reduced Boilerplate.** Less repetitive code or configuration files to write.

## Example of COC

- suffixing tests with `.spec`
- suffixing environment-specific assets, e.g. `.env.prod`
